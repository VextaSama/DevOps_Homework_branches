### Задание 1. СУБД

Кейс
Крупная строительная компания, которая также занимается проектированием и девелопментом, решила создать правильную архитектуру для работы с данными. Ниже представлены задачи, которые необходимо решить для каждой предметной области.

Какие типы СУБД, на ваш взгляд, лучше всего подойдут для решения этих задач и почему?

1.1. Бюджетирование проектов с дальнейшим формированием финансовых аналитических отчётов и прогнозирования рисков. СУБД должна гарантировать целостность и чёткую структуру данных. 

Ответ: Реляционная СУБД подходит, т.к. данные хранятся в виде таблиц, что гарантирует целостность и чёткую структуру данных.

1.2. Под каждый девелоперский проект создаётся отдельный лендинг, и все данные по лидам стекаются в CRM к маркетологам и менеджерам по продажам. Какой тип СУБД лучше использовать для лендингов и для CRM? СУБД должны быть гибкими и быстрыми. 

Ответ: Вероятно здесь подойдёт сочетание простой и понятной документно-ориентированной СУБД для лендинга, т.к. она позволяет гибко менять контент без переделывания всей базы. и реляционной СУБД для CRM, которая позволит маркетологам с помощью сложных sql запросов анализировать информацию. 

1.3. Отдел контроля качества решил создать базу по корпоративным нормам и правилам, обучающему материалу и так далее, сформированную согласно структуре компании. СУБД должна иметь простую и понятную структуру.

Ответ: Документно-ориентированная СУБД. Разбивка обучающего материала по документам образует достаточно простую структуру.

1.4. Департамент логистики нуждается в решении задач по быстрому формированию маршрутов доставки материалов по объектам и распределению курьеров по маршрутам с доставкой документов. СУБД должна уметь быстро работать со связями.

Ответ: Графовые СУБД здесь единственный вариант, т.к. графы позволяют выстраивать наиболее оптимальные и короткие пути. Для логистики это крайне важно.

Приведите ответ в свободной форме.



Задание 2. Транзакции

2.1. Пользователь пополняет баланс счёта телефона, распишите пошагово, какие действия должны произойти для того, чтобы транзакция завершилась успешно. Ориентируйтесь на шесть действий.
Приведите ответ в свободной форме.

Ответ:
1)Проводится аутентификация пользователя в системе оператора связи. Система обращается к бд пользователей для проверки учётных данных.
2)В БД оператора связи создаётся запись транзакции.
3)Система оператора связи отправляет запрос в банк на списание средств.
4)Банк проверяет наличие средств по своей БД. При достаточном балансе списывает средства, фиксируя это в своей БД.
5)Банк переводит средства на расчётный счёт оператора связи и отправляет потдверждение об успешной операции системе оператора связи, либо об отказе в случае ошибки.
6)Система оператора связи, получив подтверждение, зачисляет средства на счёт пользователя (обновляет данные в БД) и фиксирует транзакцию как завершённую, либо отклоняет транзакцию, если возникла ошибка

Задание 3. SQL vs NoSQL

3.1. Напишите пять преимуществ SQL-систем по отношению к NoSQL.

Приведите ответ в свободной форме.

Ответ:
1)Строгая структура данных
2)SQL имеет очень мощный язык запросов, что делает его лучшим выбором для сложных запросов, связанных с большим количеством таблиц.
3)В SQL-базах данных используется транзакционная модель, которая позволяет сохранять целостность данных и обеспечивать ACID
4)SQL-базы данных обеспечивают лучшую кроссплатформенность и переносимость благодаря стандартизированному языку SQL, что облегчает смену СУБД
5)SQL-базы масштабируются вертикально, то есть можно повышать нагрузку на отдельно взятый сервер и наращивать мощность центральных процессоров, а также объемы ОЗУ либо системы хранения данных.

Задание 4. Кластеры

Необходимо производить большое количество вычислений при работе с огромным количеством данных, под эту задачу выделено 1000 машин.

На основе какого критерия будете выбирать тип СУБД и какая модель распределённых вычислений здесь справится лучше всего и почему?

Приведите ответ в свободной форме.

Ответ: Здесь необходима горизонтальная масштабируемость, значит лучше всего подходят NoSQL. Раз работа будет с биг дата, значит Column-oriented NoSQL СУБД подойдёт. 
Моделью распределённых вычислений будет MapReduce. Это модель распределенных вычислений, которая параллельно обрабатывает большие объемы данных, разделяя процессы вычисления между множеством серверов.
